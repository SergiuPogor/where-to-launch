# Where to Launch

Places to launch and share your product: launch platforms, maker communities, subreddits,
directories, deal sites and marketplaces. Browse them at
[indiegoodies.com/where-to-launch](https://indiegoodies.com/where-to-launch).

Know a good place that is missing? [Add it with a pull request](CONTRIBUTING.md). Every merged
pull request is published to the site automatically.

## Layout

```
categories.json          the categories, in display order
places/<slug>.json       one place
schema/*.schema.json     JSON Schema of each file
scripts/validate.mjs     the check that runs on every pull request
```
